CSV Format

Paste comma-separated values below. One player per line. Duplicates (same Name + Version) will be skipped — so re-uploading the same file is safe.

Column order:

Name, Rating, Category, Country, Bat Hand, Bowl Hand, Bowl Style, Bat Rating, Bowl Rating, Version, Is Active

Example:

Virat Kohli, 97, Batsman, India, Right, Right, Medium Pacer, 96, 30, Base, 1 Virat Kohli, 99, Batsman, India, Right, Right, Medium Pacer, 99, 35, Legend, 1 Jasprit Bumrah, 96, Bowler, India, Right, Right, Fast, 20, 95, Base, 1 Jasprit Bumrah, 98, Bowler, India, Right, Right, Fast, 22, 98, World Cup 2023, 1

💡 Tips:
• Only Name is strictly required
• Version defaults to Base — anything else (Gold, Legend, World Cup 2023, etc.) makes it a variant
• Multiple versions of the same player are allowed — just put one row per version
• Variants auto-link to their Base card (parent_player_id) if a Base exists with the same name
• Is Active defaults to 1. Set 0/false/no to disable
• Category accepts abbreviations: "bat"→Batsman, "bowl"→Bowler, "wk"→Wicket Keeper, "ar"→All-rounder
• Hand accepts: "R"/"L"/"Right"/"Left"
• First row can be a header (auto-detected and skipped)
• This format matches the CSV from the "Download All" button — round-trip safe
