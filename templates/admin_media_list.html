🎬 Event Media (GIFs)

Upload GIFs that the bot sends during matches for milestone events. When a six is hit, a wicket falls, or a batsman reaches 50/100, the bot picks a random enabled GIF for that event and sends it to the chat. An 8-second cooldown prevents spam during heavy overs.

💡 Telegram-channel storage (recommended for uploads): Set the MEDIA_STORAGE_CHAT_ID env var to a private Telegram channel where the bot is an admin. With this configured, uploaded files are forwarded to the channel and Telegram stores them forever — your uploads survive every redeploy. URLs always work regardless.

Setup: create a private channel, add your bot as admin (with "post messages" permission), then add a message in the channel (any). Forward that message to @userinfobot to see the channel's chat_id (starts with -100). Set that as MEDIA_STORAGE_CHAT_ID in your hosting env.
⚠️ Without the channel set up: uploaded files go to local disk at data/event_media/. On free hosting tiers (Render etc.) this directory resets on every deploy. URLs always survive.
