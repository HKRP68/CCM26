🎲 Simulation Engine

ℹ️ The match engine layers ~10 modifiers (bowler, variation, pitch, phase, shot, rating, traits…) onto a base probability table. Sometimes those layers stack up and bias outcomes — e.g. too many dot balls because every layer adds +1 to dot.

These sliders apply after all per-ball modifiers and let you correct systemic biases globally without redeploying. Values are added to that outcome's probability (in percentage points). Default -8 on dots fixes the "too many dots" feedback you reported.
