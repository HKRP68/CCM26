♻️ Data Change (Override Players)

← Back to Players

CSV Format

Same format as Bulk Upload, but each row overrides an existing player's data instead of creating a new one. Players are matched by Name + Version. Rows that match no existing player are skipped and reported — nothing new is created. Changes also propagate to Challenge League data automatically.

Column order:

Name, Rating, Category, Country, Bat Hand, Bowl Hand, Bowl Style, Bat Rating, Bowl Rating, Version, Is Active

Example:

Virat Kohli, 98, Batsman, India, Right, Right, Medium Pacer, 97, 32, Base, 1 Jasprit Bumrah, 97, Bowler, India, Right, Right, Fast, 21, 96, Base, 1

⚠️ How it works:
• Each row's Name + Version is the lookup key — it identifies which existing player to update
• Every other field (Rating, Category, Country, Hands, Bowl Style, Bat/Bowl Rating, Is Active) is overwritten with the value you provide
• To rename a player or change its Version, use the player's Edit page instead (those are the match key here)
• Rows with no matching player are skipped and listed back to you — they are NOT created
• Updated players' cards re-render automatically and Challenge League entries are re-synced
• First row can be a header (auto-detected and skipped)
