What a legal squad looks like — the size, the overseas cap, and how many of each role. Blank is not zero. A blank Max means the role has no ceiling; a typed 0 means none of that role may be signed at all, which is a rule some pools really want. A blank or 0 Min means no floor.

The two ends are enforced differently, and they have to be. A maximum is a fact about the squad in front of you, so the bid that would break it is refused outright. A minimum is a promise about a squad that does not exist yet, so it is enforced as reachability — a bid is refused when winning it would leave the franchise without enough slots to still fill what it owes. A rule you only meet once you have broken it is one you cannot plan around.

Min squad also drives the money side of reachability: a franchise may never bid so much that it could not still fill its remaining slots at the pool's cheapest base price ({{ money(season.min_base_price_lakh) }}). Every franchise's ceiling is shown below and on the board.

📦 The field, as a file

Twelve sides with owners, co-owners, cities and purses is twenty minutes of form-filling to reproduce, and every minute of it is a chance to mistype a Telegram id. Download the field, keep it, upload it into the next auction.
Only what an admin typed is imported — names, short names, cities, owners, co-owners, opening purses, RTM cards and expansion picks. The purse remaining, the squad and the ledger are results, not rules, so an import never touches them. The file carries each squad under "squad" so it reads as a record of the season, and the importer ignores that key.

⬇️ Download franchises (JSON)

Franchises are matched by name, case aside, which is what makes the same file safe to upload twice: the second upload edits the field the first one created rather than doubling it. A changed opening purse on a franchise that already exists is applied as a ledger correction, not written over the column, so the purse and its ledger never end up describing different auctions.
Remove franchises the file leaves out takes them the way /aremoveteam does — players back into the pool, purse shared among the rest. It is off by default because an import is far more often "here is the field" than "and nobody else".

{% endif %} {% endif %} {{ fold("rtm", "🪪 Right To Match", ("on · " ~ season.rtm_per_team ~ " each" if season.rtm_enabled else "off")) }}

The IPL 2025 rule, in full. When a lot's clock expires, the franchise that held the player last season is asked whether it wants to use an RTM. If it says yes, the standing top bidder gets one more raise — and only then does the holder match that final number, or let him go. The price is the final bid, not the one that triggered it.
Each of the three windows times out to the safe answer, so a franchise nobody is running can never wedge the auction.

A premium of 0 is the pure IPL rule — matching costs exactly the final bid. Set it higher and holding a card costs something to use. Saving deals the card count out to every franchise that has not spent one yet; a franchise mid-auction keeps whatever it has left.
