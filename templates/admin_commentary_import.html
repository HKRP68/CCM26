📖 Format reference

The file should contain a single Python dict named cricket_commentary (or any name — the parser finds it automatically). Keys are event names, values are lists of strings. Standard event keys:

dot, one, two, three, four, six,
wicket_bowled, wicket_caught_fielder, wicket_caught_keeper, wicket_lbw, wicket_stumped,
extras, milestones, general

Use {batsman}, {bowler}, {fielder}, {keeper}, {runs} as placeholders.
