➕ Add stadiums from JSON paste one ground or a list

Adds the grounds in the paste and updates any whose name already exists. Nothing else is touched. Out-of-range values are clamped and unknown keys dropped — each is reported back. For a CSV, a full export bundle, modifiers, or to replace the whole list, use Import, which previews first.

Example JSON 
{
  "name": "Perth Stadium",
  "aliases": ["Optus Stadium", "Perth"],
  "city": "Perth",
  "country": "Australia",
  "altitudeMeters": 5,
  "boundaryM": { "squareLeg": 72, "fineLeg": 68, "longOn": 82, "longOff": 80 },
  "outfieldSpeed": 88,
  "dewFactor": 25,
  "avgFirstInningsScore": 175,
  "slope": false,
  "climate": { "cloudCover": 20, "humidity": 45, "rainChance": 10, "temperatureC": 28, "windKPH": 22 },
  "modifiers": { "bounce": 1.15, "pace": 1.05 }
}

Only name is required; anything left out takes its default. Several grounds at once go in a list — [{…}, {…}] — or under a "stadiums" key. country is what groups the ground below. Boundaries are metres (40–100), outfieldSpeed and dewFactor are 0–100, and each modifiers value is 0.5–2.0, where 1.0 means no effect. Channels: {{ modifier_channels|join(', ') }}.
