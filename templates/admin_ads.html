🔀 Switching ad network

The network is chosen entirely by env vars — no code change, no redeploy of the Mini App code itself:

NetworkEnv vars
Monetag AD_PROVIDER=monetag, MONETAG_ZONE_ID=<zone>, optional MONETAG_SDK_URL=<host from your SDK tag>
Adsgram AD_PROVIDER=adsgram, ADSGRAM_BLOCK_ID=<block>
None (mock) AD_PROVIDER=none

Leave AD_PROVIDER unset and it auto-detects: Monetag if a zone is set, else Adsgram if a block is set. Postbacks already delivered by the outgoing network stay claimable, so a switch never eats a pending reward.

🔧 Monetag setup
  1. Sign up at monetag.com and add your Telegram Mini App as a site (the t.me/<bot>/<app> link, plus the web app URL from @BotFather → /myapps)
  2. Create an ad zone of type Rewarded Interstitial (SDK / Telegram Mini App)
  3. Open the zone's SDK tag. It looks like:
    <script src='//libtl.com/sdk.js' data-zone='1234567' data-sdk='show_1234567'></script> ↑ The number is your zone ID. The host can differ per account — copy it exactly.
  4. Set env vars and redeploy:
    AD_PROVIDER=monetag
    MONETAG_ZONE_ID=1234567
    MONETAG_SDK_URL=https://libtl.com/sdk.js
  5. Optional but recommended — in the zone's Postback settings, set the S2S URL to:
    {{ public_base_url }}/api/ads/reward?ymid={ymid}&telegram_id={telegram_id}&event_type={event_type}&reward_event_type={reward_event_type} Keep the {…} macros literal — Monetag substitutes them. Include all four: telegram_id is resolved by Monetag and is preferred over ymid, which is whatever the Mini App handed the SDK and so is client-controlled. Click events are ignored here so one view can't pay out twice, and not_valued events — impressions that earned nothing — are dropped rather than paid out of your economy.
  6. Verify: this page should show "✅ Monetag is LIVE", and postbacks appear in the table below
🔧 Adsgram setup
  1. Sign up at partner.adsgram.ai
  2. Click "Create" → "Ad Platform". Enter:
    • App name: CricMaster Ultra
    • Telegram direct link + Web app URL: get from @BotFather → /myapps
    • Bot ID: first part of your token before the colon
  3. Click "Create" → "Ad unit". Choose Reward block type
  4. In Ad unit settings, set Reward URL to:
    {{ public_base_url }}/api/ads/reward?userid=[userId] ↑ Keep [userId] literal — Adsgram substitutes it. The old /api/adsgram/reward path still works, so an existing block needs no edit.
  5. Submit for moderation (DM @adsgramsupport on Telegram with platform link)
  6. After approval, click "Show code" → copy the Block ID
  7. Set env vars and redeploy:
    AD_PROVIDER=adsgram
    ADSGRAM_BLOCK_ID=<your_block_id>
  8. Verify here: this page should show "✅ Adsgram is LIVE" instead of "⚠️ Mock mode"
