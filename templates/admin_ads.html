🔧 Adsgram setup
  1. Sign up at partner.adsgram.ai
  2. Click "Create" → "Ad Platform". Enter:
    • App name: CricMaster Ultra
    • Telegram direct link + Web app URL: get from @BotFather → /myapps
    • Bot ID: first part of your token before the colon
  3. Create a Reward ad block and submit it for moderation. Copy its numeric ID from Show code.
  4. Set ADSGRAM_BLOCK_ID on the host that serves the Mini App. The app can save SDK completions with this setting alone.
  5. For optional server callbacks, set ADSGRAM_POSTBACK_SECRET on that host and enter this Reward URL in the Adsgram Reward block.
    {{ public_base_url }}/api/ads/reward?userid=[userId]&secret=YOUR_SECRET Keep [userId] literal. Replace YOUR_SECRET with the same random secret you set on the server (at least 32 characters). Configure this on the ad unit and redact query strings from access logs.
  6. To require server confirmation for every credit, set ADSGRAM_REQUIRE_POSTBACK=1 once you have verified callback delivery with a live rewarded ad.
