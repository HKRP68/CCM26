💡 Egress Optimization Notes

Hot paths now use in-memory caches:

  • /claim, /daily, /gspin — random player picked from cache, only the chosen ID hits the DB
  • /playerinfo, /buy, /searchpl — cache-first lookup; DB hit only for fresh data
  • Match scorecard cards — generated card PNGs cached, regenerate only on player edit
  • Custom card images — bytes cached after first read

If you suspect a query is leaking egress, check activity_log: every action logs there. A user repeatedly browsing rosters or running searches can each generate ~10 KB of egress per view. Old activity log entries are safe to delete — they're for the news feed, which only shows the last 15 entries per user.
