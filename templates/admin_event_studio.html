Registration cutoff

Automatic, and not an authored field. A Live Event takes players until its first fixture deadline, because a campaign's fixtures are written when someone joins and a later joiner would get one they could never play. A Moment or Boss Battle has no fixtures, so it takes players right up to the end date.

Match configuration

Every Live Event match plays exactly like a normal CIPL match, on the same engine: XI selection, batting order, captain, toss, bowler and approach choices, ball-by-ball commentary, the completed Over Card after every over, projected score and chase comparison, innings break, Super Over where enabled, scorecard and summary.

Pitch, venue and weather are per fixture, not per event: generating the schedule draws each one. Narrow the grounds with venue countries on the Schedule step, or set a single fixture's own on the Advanced step.

Points table

Standings are ordered by points, then wins, then net run rate, and the playoffs read those official final standings.

AI manager personalities

Assign profile keys such as aggressor, wall or architect. An empty allowlist uses all ten. Tactical calibration is still in staging.

How locks and generation interact

Use source: "manual" for a hand-authored fixture, or locks to keep specific fields on a generated one. Reward locks use tier.result.asset. Set objectives_locked to keep the objective list during regeneration.

A fixture's pitch, venue and weather are drawn when you generate the schedule. Edit one on its row and it is kept on the next run. The draw is reproducible: the same draft regenerates the same grounds, and changing the condition seed re-rolls every one.

Dates without an offset use the event timezone. Enter budgets before generating rewards.
