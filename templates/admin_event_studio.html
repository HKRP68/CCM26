Draft configuration

Copying a league fills Team details and Squads below with every active team's name, short name, logo, colours and full squad, and takes the league's overseas rules with it. It replaces the draft's current team list.

Overview

Pick each date and time from the calendar. They use your selected timezone. A time that crosses a daylight-saving boundary needs an explicit UTC offset instead — set it in Full configuration and the field below turns into a text box showing it.

There is no enrollment deadline to set. A Live Event takes players until its first fixture deadline, because a campaign's fixtures are written when someone joins and a later joiner would get one they could never play. A Moment or Boss Battle has no fixtures, so it takes players right up to Closes.

Teams and squads

Two views of the same team list, kept in step as you type. Team details holds the identity and branding; Squads holds each team's master card IDs.

Teams, fixture locks and budgets

Each team needs a lowercase key, a name and a list of master card IDs in players. An optional xi is an ordered list of 11 IDs. Copying Challenge Data replaces the draft team list.

Use source: "manual" for a manually authored fixture or use locks to keep specific fields. Reward locks use tier.result.asset. Set objectives_locked to keep the objective list during regeneration.

A fixture's pitch, venue and weather are drawn when you generate the schedule. Edit one on its row and it is kept on the next run, or name it in locks. The draw is reproducible: the same draft regenerates the same grounds, and changing the condition seed re-rolls every one.

Dates without an offset use the event timezone. Enter budgets before generating rewards.
