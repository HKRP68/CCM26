+ New Quest

Drops this period's set for every user — old quests go, new ones are drawn from the live catalogue on their next quest read. Use it after editing quests so changes reach players immediately instead of at the next daily/monthly rollover. Completed-but-unclaimed quests are auto-claimed first, so nobody loses a reward they earned.

ℹ️ Quest progress is event-driven. Each quest has an event_key the engine fires, counted over that quest's own period — wickets_taken on a Monthly quest is “Wickets Taken in Month”.
⚠️ Quests with event_key=manual have no trigger behind them and are never dealt in the random draw — progress only moves when an admin bumps it on the user detail page. Pin one (Always assign) if you intend to run it.
⚖️ Match quests only count when a user's own XI plays another user's own XI. Bot matches (/vsbot, /wpmbot, /lpbot, /ciplbot), spectator matches and matches voided by the 10+ Team Overall gap earn no quest progress.
