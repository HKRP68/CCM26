Recovery tips

  • Keep a private record of your Telegram user ID and game account ID for future support.
  • If the game data itself was deleted, restore a database backup before transferring.
  • If the new ID already has a squad or money, review both accounts before confirming replacement. Its current data stays in a disabled archive; the old account's balances and squad become active.
