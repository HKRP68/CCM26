🎯 Player Drafts

Create a draft

Teams pick their squads live in a Telegram group. When every slot is filled, publish the draft and the squads become a playable Challenge League.

  1. Create the draft here.
  2. Open it and upload the player pool and the draft order.
  3. In the Telegram group, run /dbind <id> then /dstart.
  4. Owners type /pick <player> when they're on the clock.
  5. When it's done, /dpublish (or the button on the draft page).
