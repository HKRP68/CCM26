/cmucareer asks the player for a country, a first-name initial and a surname initial, then builds a name by combining one first name and one surname from this pool. Every generated name is checked against every existing player, so a career player never shares a name with a real card or with someone else's career player. Only letters that actually have names behind them are offered, so the wizard can't dead-end.

Adds any missing real-player names. Never removes names you added by hand.
