How it works

  • New commands blocked: /playmatch, /vsbot, /claim, /daily, etc. all return the maintenance message.
  • Live matches continue: taps on inline buttons (shot selection, fielding, etc.) bypass the lock so users can finish.
  • Auto-expire: if ETA is set and passes, users are unlocked automatically — but the admin must click "Disable & Resume" to fully turn off maintenance and clear the start time.
  • Bypass list: admins listed there can use any command for testing. Find your telegram_id by messaging @userinfobot.
  • Cache: the bot caches config in memory. Saving here auto-invalidates the cache so changes take effect on the next message.
