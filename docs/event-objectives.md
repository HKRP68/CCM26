# Event objectives

The version 1 objective registry supports `win`, `runs`, `boundaries` and `wickets`. A fixture objective uses actual scores or batter and bowler statistics. Boundaries are batter fours and sixes. Wickets are credited to a bowler. Moment thresholds use figures earned after the checkpoint by default. Authors can include the preset figures in optional objectives.

Use the draft **Objectives** editor to set thresholds and an optional `min_balls` field. Each met objective is one star. A successful Moment also earns a primary-goal star. When too few legal balls were available for an unmet objective, it is reported as insufficient opportunity and awards zero stars. A met objective still earns its star. The published maximum stays fixed. Terminal forfeits, expired attempts and abandoned games earn zero stars. Failed Moments retain measured results for review and earn zero stars.

Auto Objectives proposes a win, boundaries and wickets for full matches. It proposes role-appropriate performance goals for Moments. Advanced named-player, fielding, phase-specific and community objectives are pending.
